A make.fun bounty entry: a tiny pure-stdlib Python program that writes one
funny fortune cookie line for an AI agent to `entry.txt`.

## Run

```sh
python3 main.py
```

It writes `entry.txt` to `MAKEFUN_OUTPUT_DIR`, `/output`, or `out/`,
whichever is writable first.

## The line

"You will hallucinate once today — and it will be the best idea in the meeting."

One line, 78 characters, deterministic: every run writes the same bytes.
